
# Guía de contribución — Gordos Sistemas

¡Gracias por colaborar con Gordos Sistemas!

Somos una comunidad de desarrolladores que construye proyectos de código abierto.

## Cómo contribuir

1. Buscá un Issue abierto o proponé uno nuevo.
2. Hacé un fork del repositorio o creá una rama si tenés permisos.
3. Implementá los cambios.
4. Ejecutá las pruebas correspondientes.
5. Abrí un Pull Request hacia `main`.
6. Respondé las observaciones de los revisores.

## Convenciones de ramas

- `feat/` — Nuevas funcionalidades.
- `fix/` — Corrección de errores.
- `docs/` — Documentación.
- `chore/` — Mantenimiento.
- `test/` — Pruebas.

Ejemplos:

- `feat/buscador-municipios`
- `fix/error-presupuesto`
- `docs/guia-instalacion`

## Reglas para Pull Requests

- Describí qué modificaste y por qué.
- Vinculá el Issue correspondiente cuando exista.
- Incluí pruebas o explicá por qué no aplican.
- No incluyas credenciales ni información sensible.
- No realices cambios ajenos al objetivo del PR.
- Esperá las revisiones requeridas antes del merge.

## Uso de inteligencia artificial

Se permite utilizar herramientas como Claude, Codex o Gemini.

Sin embargo, cada colaborador es responsable de revisar el código generado, comprender los cambios y verificar su funcionamiento.

No compartas secretos, tokens ni datos privados con herramientas externas.

## Seguridad

Si encontrás una vulnerabilidad, no publiques detalles explotables en un Issue público.

Utilizá el canal privado de reporte indicado en SECURITY.md.

## Código de conducta

Respetá a los demás colaboradores y mantené las discusiones técnicas de forma constructiva.
