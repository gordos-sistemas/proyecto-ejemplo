
# Gordos Sistemas — Plantilla de proyecto

Plantilla base para los proyectos open source
de la comunidad Gordos Sistemas.

## Objetivo

Facilitar la creación de repositorios con
documentación, procesos de colaboración
y controles de seguridad consistentes.

## Crear un proyecto

1. Hacé clic en "Use this template".
2. Elegí el nombre del nuevo repositorio.
3. Configurá la descripción y el README.
4. Asigná los maintainers correspondientes.
5. Adaptá CODEOWNERS al equipo del proyecto.
6. Configurá las reglas de protección de main.
7. Adaptá los workflows al stack utilizado.

## Estructura

- CONTRIBUTING.md: guía para colaboradores.
- SECURITY.md: política de seguridad.
- .github/CODEOWNERS: responsables del código.
- .github/PULL_REQUEST_TEMPLATE.md: plantilla de PR.
- .github/ISSUE_TEMPLATE/: formularios de Issues.
- .github/workflows/: validaciones automáticas.

## Flujo de contribución

1. Crear un Issue o seleccionar uno existente.
2. Crear una rama de trabajo.
3. Implementar y probar los cambios.
4. Abrir un Pull Request.
5. Superar las validaciones de CI.
6. Obtener las aprobaciones requeridas.
7. Integrar los cambios en main.

## Seguridad

Nunca publiques credenciales, tokens,
claves privadas ni información sensible.

Los reportes de vulnerabilidades deben
realizarse por canales privados.

Consultá SECURITY.md.

## Inteligencia artificial

Se permite utilizar herramientas de IA
para colaborar en el desarrollo.

Cada contribuidor debe revisar y validar
los cambios antes de enviarlos.
